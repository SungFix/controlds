Segurança da sessão

As senhas usam PBKDF2 quando o navegador oferece Web Crypto. O sistema bloqueia automaticamente após 30 minutos sem atividade.

Com o Supabase configurado, os dados são sincronizados entre computadores. Sem configuração, o sistema permanece em modo local neste navegador.
